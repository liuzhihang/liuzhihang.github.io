    A 社新 Skill ELI5：请把我的同事当成 5 岁

    贴图·2026年8月23日·AI·303 字·约 2 分钟

    ELI5 是 “explain like I’m 5” 的缩写，意思是“像对 5 岁小孩解释那样说明白”。

    它最有意思的地方，不是多了一套复杂能力，而是把“怎样才算解释清楚”写成了一句约束：

    讲不清架构设计？先用 /eli5，把你的同事暂时“当成 5 岁”：假设对方毫无背景，去掉术语，用大图建立共同背景，再逐层补上技术细节。

    这样讲模块逻辑、架构设计或事故原因时，就不容易再出现“自己讲了半天，对方还是没听懂”。

    ELI5 是谁写的

    ELI5 由 Anthropic Claude Code 团队成员 Thariq Shihipar 编写并提交，最近也有人在 Anthropic 内部使用。目前它先放在 Anthropic 管理的社区插件目录中；Thariq 还提到，团队正在讨论是否把它作为官方插件。

    怎么使用

    Claude Code 安装方法：

    claude plugin marketplace add anthropics/claude-plugins-community
claude plugin install eli5@claude-community

    装好后直接输入：

    /eli5 这个模块是如何工作的

    如果只是偶尔使用，不安装也可以，直接复制这句提示词：

    请把我当成对这个话题一无所知的人，用一个包含大图、文字较少的 HTML 页面向我解释。
