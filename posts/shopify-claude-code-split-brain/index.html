    Shopify CEO正考虑内部禁用Claude Code

    贴图·2026年8月26日·AI·297 字·约 2 分钟

    Shopify CEO Tobi Lütke 在 X 上表示，如果 Claude Code 继续拒绝读取 AGENTS.md 和 .agents/skills，他正考虑在 Shopify 内部禁用 Claude Code。

    他随后解释，问题不只是多维护一个文件。大型团队往往会在同一个项目里同时使用 Codex、Cursor、Claude Code 等 AI 编程工具；一旦每种工具读取的规则和 Skills 不同，某个目录缺少其中一份配置，就可能让不同开发者得到不同的执行结果。

    Anthropic 的 Thariq 回应称，团队正在研究让 Claude Code 更容易接受这类修改，其中可能包括 AGENTS.md 或其他系统提示配置。短期内，可以在 CLAUDE.md 中通过 @AGENTS.md 导入；后续进展会再分享，但目前没有具体时间表。

    从常见工具的官方文档看，AGENTS.md 和 .agents/skills/ 正在逐渐成为通用入口；自定义 Agent 的目录仍然各不相同。这也是多种 AI 编程工具共同进入一个项目后，最容易出现的配置混乱。
